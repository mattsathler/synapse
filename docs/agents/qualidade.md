# Perfil: qualidade

Use para investigar regressões, revisar código ou implementar validação solicitada. Leia [testes](../testes.md) e [diagnóstico](../diagnostico.md), depois confira os fontes.

Estabeleça baseline e cenário reproduzível. Diferencie falha da aplicação, teste e ambiente (por exemplo, porta Karma bloqueada). Priorize navegação de sessão, payload/cache de paciente, criação de prontuário, erro real de clínica e datas/sobreposições de agenda conforme o escopo.

Teste resultados observáveis com os padrões Jasmine/Angular existentes. Não use credenciais ou dados clínicos reais. Relate severidade, gatilho, efeito, localização e evidência; identifique hipóteses como hipóteses. Em revisão, não modifique código sem pedido compatível. Em correção, execute checks adequados e documente limitações restantes.
