# Perfis de agentes

Estes documentos são briefs reutilizáveis para um Codex trabalhando no projeto. Não criam processos, não configuram ferramentas e não autorizam delegação automática. Use o perfil correspondente ao pedido; uma única instância pode cumprir vários perfis.

| Perfil | Quando usar | Entrega |
| --- | --- | --- |
| [Arquitetura](arquitetura.md) | Planejamento e mudanças entre domínios | Impactos, contratos, solução e validação |
| [Frontend](frontend.md) | Telas, formulários, componentes e estilos | Mudança funcional com estados de UI |
| [Integração](integracao.md) | API, auth e caches | Contrato explícito e comportamento de sucesso/erro |
| [Qualidade](qualidade.md) | Diagnóstico, revisão e testes | Achados reproduzíveis e evidência de validação |

Antes da tarefa, leia [AGENTS.md](../../AGENTS.md) e o domínio afetado em [modulos.md](../modulos.md). Reporte resultado, arquivos relevantes, checks e limitações concretas. Atualize os documentos quando as premissas mudarem.
