# Skills do Synapse

Skills locais, mantidas nesta pasta por escolha do projeto. Cada diretório contém um `SKILL.md` com name/description e procedimento. Elas referenciam documentação pela posição no repositório; mantenha essa estrutura ao utilizá-las.

| Skill | Quando ler |
| --- | --- |
| [synapse-feature](synapse-feature/SKILL.md) | Implementar/alterar funcionalidades do frontend |
| [synapse-api](synapse-api/SKILL.md) | Alterar auth, chamadas HTTP, payloads e caches |
| [synapse-validation](synapse-validation/SKILL.md) | Diagnosticar falhas e validar mudanças |

Para uso direto, peça ao Codex para ler o caminho completo da skill junto da tarefa. Os arquivos aqui são referências locais; sua presença em `docs` não é uma declaração de instalação ou descoberta automática. Não foram instalados em configuração global nem copiados para outro diretório. Se forem movidos no futuro, ajuste os links relativos ou mantenha referências ao checkout.
